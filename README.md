# Encore: The Last Heist

**เกมโจรกรรมสยองขวัญแบบผู้เล่นหลายคน (Multiplayer Horror Heist)**

## เกี่ยวกับเกม (About the Game)

Encore: The Last Heist เป็นเกมแนวสยองขวัญและโจรกรรมแบบผู้เล่นหลายคน โดยผู้เล่นจะได้รับบทเป็นโจรที่ต้องบุกเข้าไปขโมยสิ่งของมีค่าภายในบ้านไม้ร้างแห่งหนึ่ง เพื่อสะสมมูลค่าของสิ่งของให้ได้มากที่สุดเพื่อเอาชนะโจรคนอื่นๆ
อย่างไรก็ตาม บ้านหลังนี้ไม่ได้ร้างอย่างที่คิด เพราะมีหญิงสาวลึกลับอาศัยอยู่ภายในบ้านแต่แท้จริงแล้วเธอคือ **เสือสมิง** สิ่งมีชีวิตเหนือธรรมชาติที่ปลอมตัวเป็นมนุษย์ ผู้เล่นจึงต้องระมัดระวังตัวและเอาชีวิตรอดจากเสือสมิงไปพร้อมกับการค้นหาสิ่งของมีค่าโดย
ผู้เล่นมีเวลาเพียง **3 นาที** ในการขโมยสิ่งของให้ได้มูลค่ามากที่สุด นอกจากจะต้องเอาตัวรอดจากเสือสมิงแล้วผู้เล่นยังสามารถขัดขวางคู่แข่งด้วยการทืบผู้เล่นคนอื่นเพื่อทำให้ล้มลง และสร้างความได้เปรียบในการแข่งขันได้อีกด้วย
เมื่อหมดเวลาลง ผู้เล่นที่สามารถรวบรวมสิ่งของที่มีมูลค่ารวมสูงที่สุดจะเป็นผู้ชนะ

## รูปแบบการเล่น (Gameplay Features)
- **การแข่งขันแบบผู้เล่นหลายคน (Multiplayer Competition)** — แข่งขันกับผู้เล่นคนอื่นเพื่อรวบรวมสิ่งของที่มีมูลค่าสูงที่สุด
- **การเอาชีวิตรอดจากความสยองขวัญ (Horror Survival)** — ระวังเสือสมิงที่ซ่อนตัวอยู่ภายในบ้านและพยายามเอาชีวิตรอดจากมัน
- **จำกัดเวลา (Time Limit)** — ผู้เล่นมีเวลาเพียง 3 นาทีในการขโมยสิ่งของ
- **การค้นหาและเก็บสิ่งของ (Loot Collection)** — สำรวจบ้านเพื่อค้นหาสิ่งของมีค่าและเพิ่มมูลค่าทรัพย์สินที่ขโมยมา
- **การขัดขวางคู่แข่ง (Player Interaction)** — ทืบผู้เล่นคนอื่นเพื่อทำให้ล้มลงและขัดขวางการดำเนินเกมของคู่แข่ง
- **การตัดสินใจภายใต้ความเสี่ยง (Risk and Reward)** — เลือกว่าจะเสี่ยงสำรวจพื้นที่อันตรายเพื่อค้นหาสิ่งของมีค่า หรือหลีกเลี่ยงเสือสมิงเพื่อความปลอดภัย

## เป้าหมายของเกม (Game Objective)
1. เข้าไปภายในบ้านไม้ร้างเพื่อเริ่มต้นการโจรกรรม
2. สำรวจบ้านและค้นหาสิ่งของที่มีมูลค่า
3. หลีกเลี่ยงเสือสมิงและเอาชีวิตรอดระหว่างการโจรกรรม
4. ขัดขวางคู่แข่งด้วยการทืบเพื่อทำให้ผู้เล่นคนอื่นล้มลง
5. รวบรวมสิ่งของให้ได้มูลค่ารวมสูงที่สุดก่อนหมดเวลา 3 นาที

**ขโมยให้ได้มากที่สุด เอาชีวิตรอดจากเสือสมิง และเอาชนะโจรคนอื่นให้ได้!**
